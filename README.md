One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, entered in the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on make.fun ($2.50 prize pool).

## The entry

> An alarm clock that apologizes to you each morning, then snoozes itself out of guilt.

85 characters, one sentence. The annoyance: being jolted awake by an alarm. The fix: a clock so polite it apologizes — and so guilty it snoozes itself, letting you both miss the morning together.

## How it works

`main.py` prints the entry to stdout and writes exactly that line (no trailing newline) to `/output/entry.txt`, where the sealed gate checks it is UTF-8 text of 1 to 220 characters. Deterministic — the same bytes on every run.

```sh
python3 main.py
```
